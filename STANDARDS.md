# Content Standards

These standards apply to every concept page, calculator, and section in this
project. Read this file before building any new page. Existing pages should
be brought in line with these standards over time.

## Audience & tone

Write for someone with **zero prior finance/accounting/tax knowledge** — a
sharp teenager or an adult beginner encountering the topic for the first
time.

- No jargon without immediately defining it in plain words, inline, the
  first time it's used on a page.
- No assumed context. Don't assume the reader knows what a "brokerage
  account," "amortization," or "opportunity cost" means unless it has
  already been explained on that page or on a page it links to.
- One concrete, relatable example per concept.
  - **Foundational concepts** → everyday scenarios: saving allowance,
    splitting a pizza bill, running a lemonade stand.
  - **More advanced concepts** → realistic scenarios: a person's paycheck,
    a small business, a mortgage.

## First-principles requirement

Every concept page's "Why this exists" section must explain the actual root
problem the concept solves — not just define the concept.

For example: don't just say "compound interest is interest on interest."
Explain why interest exists at all first (lending money has a cost and a
risk, so lenders are compensated for both), and only then build up to why
that compensation compounds over time.

If a concept depends on an idea from [Economics Foundations](#economics-foundations-foundations),
link to it rather than re-explaining it from scratch.

## Economics Foundations (`/foundations`)

A lightweight section, separate from Finance/Accounting/Taxation (not a full
pillar), covering only the handful of ideas that finance concepts depend on.
Keep this section small — **5-6 pages max**, not a full economics
curriculum.

Planned pages:

1. Scarcity & opportunity cost
2. Supply & demand
3. Incentives
4. Inflation (the economic cause, not just "prices go up")
5. What an interest rate fundamentally is

Finance, accounting, and taxation pages should link to these pages wherever
they assume the reader already understands one of these ideas, rather than
re-deriving it inline.

## Process

- Before building any new page, read this file first.
- When a gap between an existing page and these standards is found, fix it
  as part of related work rather than leaving it inconsistent.
